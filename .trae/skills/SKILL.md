# Skills 目录

本目录包含项目自定义的 Skills，用于规范开发流程和代码质量。

## 可用 Skills

### code-conventions
- **路径**: `.trae/skills/code-conventions.md`
- **用途**: TypeScript 代码规范，防止常见编译错误
- **触发时机**: 编写 TypeScript 代码时、代码审查时、修复类型错误时

## 如何使用

1. 在编写 TypeScript 代码时，参考 `code-conventions.md` 中的规范
2. 在代码审查时，检查是否违反了规范
3. 在修复类型错误时，查阅规范中的解决方案
