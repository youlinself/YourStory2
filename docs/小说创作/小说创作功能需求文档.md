# 小说创作功能需求文档

> 本文档用于指导小说创作功能的开发实施，确保新会话可以基于此文档直接进行开发设计。

---

## 一、产品概述

### 1.1 功能定位

| 功能模块 | 说明 |
|---------|------|
| **对话创作** | 玩家以对话形式，创作自己的人生故事（自传） |
| **小说创作** | 玩家以协作形式，创作虚构的小说作品（新增功能） |

### 1.2 核心区别

| 维度 | 对话创作 | 小说创作 |
|------|---------|---------|
| **创作类型** | 自传/回忆录 | 虚构小说 |
| **视角** | 第一人称（我） | 第一/第三人称可选 |
| **内容来源** | 用户真实经历 | 用户想象/创意 |
| **AI角色** | 引导者/采访者 | 创作助手/编辑 |
| **结构** | 时间线驱动 | 情节/章节驱动 |
| **核心体验** | 回忆与记录 | 构思与创作 |

### 1.3 核心原则

1. **创作自由**：不限题材、风格、长度，用户拥有完全创作自由
2. **AI辅助而非替代**：AI提供建议、润色、扩展，但创作权在用户
3. **结构化创作**：提供大纲、角色、世界观等管理工具
4. **降低门槛**：提供模板、示例、灵感激发，帮助快速开始

```
┌─────────────────────────────────────────────────────────────┐
│  [我的小说]    [创作中 ▼]    [角色管理]    [设置]            │
├─────────────────────────────────────────────────────────────┤

```

### 2.2 数据模型

```
Novel（小说）
├── id: string
├── title: string
├── genre: enum                // 题材：玄幻/言情/科幻/悬疑/历史/现代/...
├── synopsis: string           // 简介
├── coverImage: string         // 封面图片
├── targetWordCount: number    // 目标字数

├── status: enum               // 状态：构思中/写作中/已完成/暂停

├── characters: Character[]    // 角色列表
├── worldBuilding: WorldBuilding  // 世界观设置
├── tags: string[]             // 标签
├── createdAt: datetime
└── updatedAt: datetime

├── id: string

├── title: string

├── content: string            // 章节内容
├── summary: string            // 章节概要
├── status: enum               // 状态：大纲/草稿/润色/定稿
├── wordCount: number          // 字数
├── notes: string              // 创作笔记
├── createdAt: datetime
└── updatedAt: datetime

Character（角色）
├── id: string
├── novelId: string            // 所属小说ID
├── name: string               // 角色名
├── alias: string[]            // 别名
├── role: enum                 // 角色定位：主角/配角/反派/龙套
├── gender: enum               // 性别
├── age: number                // 年龄
├── appearance: string         // 外貌描写
├── personality: string        // 性格特点
├── background: string         // 背景故事
├── goals: string              // 目标/动机
├── relationships: Relationship[]  // 关系网
├── avatar: string             // 头像
├── notes: string              // 备注
└── createdAt: datetime

WorldBuilding（世界观）
├── id: string
├── novelId: string            // 所属小说ID
├── setting: string            // 世界设定概述
├── era: string                // 时代背景
├── location: string           // 主要地点
├── magicSystem: string        // 力量体系（如适用）
├── factions: string[]         // 势力/组织
├── rules: string[]             // 世界规则
├── notes: string              // 备注
└── updatedAt: datetime
```

## 三、功能模块设计

### 3.1 小说管理

#### 3.1.1 创建新小说

| 步骤 | 内容 | 说明 |
|------|------|------|
| 1 | 选择创作方式 | 空白创建 / 模板创建 / AI辅助创建 |
| 2 | 填写基本信息 | 书名、题材、简介、目标字数 |
| 3 | 可选：设置世界观 | 时代背景、主要地点等 |
| 4 | 可选：添加初始角色 | 主角设定 |
| 5 | 进入创作界面 | 默认进入大纲视图 |

#### 3.1.2 创作方式

| 方式 | 适用场景 | 交互形式 |
|------|---------|---------|
| **空白创建** | 有完整构思 | 直接创建空白小说，自由写作 |
| **模板创建** | 需要结构参考 | 选择模板（如：三幕式、起承转合、英雄之旅） |
| **AI辅助创建** | 只有模糊想法 | 回答几个问题，AI生成初始设定建议 |

### 3.2 大纲管理

#### 3.2.1 大纲视图

| 功能 | 说明 |
|------|------|
| 章节列表 | 显示所有章节，支持拖拽排序 |
| 章节状态 | 用颜色/图标标识：大纲/草稿/润色/定稿 |
| 进度统计 | 各章节字数、总字数、完成百分比 |
| 快速操作 | 添加/删除/重命名章节 |

#### 3.2.2 章节操作

| 操作 | 说明 |
|------|------|
| 添加章节 | 在指定位置插入新章节 |
| 删除章节 | 删除章节（需确认） |
| 合并章节 | 将多个章节合并为一个 |
| 拆分章节 | 将一个章节拆分为多个 |
| 调整顺序 | 拖拽调整章节顺序 |

#### 3.2.3 大纲模板

| 模板名称 | 结构 | 适用题材 |
|---------|------|---------|
| 三幕式 | 开端→对抗→结局 | 通用 |
| 起承转合 | 起→承→转→合 | 短篇/中篇 |
| 英雄之旅 | 启程→启蒙→归来 | 玄幻/冒险 |
| 章回体 | 多章回，每回独立故事 | 传统/历史 |
| 网状叙事 | 多线并行，相互交织 | 悬疑/群像 |

| 润色 | 优化语句，提升文采 |
| 取名 | 为角色、地点、技能等生成名字 |
| 情节建议 | 根据当前情节，建议后续发展 |

## 五、AI功能设计

### 5.1 AI创作助手

#### 5.1.1 核心能力

| 能力 | 说明 |
|------|------|
| 文本生成 | 根据提示生成连贯的叙事文本 |
| 风格适配 | 学习并模仿用户的写作风格 |
| 上下文理解 | 理解角色、情节、世界观等上下文 |
| 创意生成 | 提供新颖的情节、角色、设定建议 |

#### 5.1.2 使用场景

| 场景 | AI行为 |
|------|--------|
| 用户输入"萧炎感到..." | AI续写："萧炎感到体内斗气翻涌，一股前所未有的力量正在觉醒..." |
| 用户选中一段文字 | AI提供润色建议，保持原意但提升文采 |
| 用户点击"情节建议" | AI根据当前情节，提供3-5个可能的发展方向 |
| 用户点击"取名" | AI根据描述，提供多个命名选项 |

### 5.2 AI交互原则

| 原则 | 说明 |
|------|------|
| 辅助而非替代 | AI提供建议，最终决定权在用户 |
| 保持风格 | AI学习用户风格，不强行改变 |
| 可控性 | 用户可以控制AI的参与程度 |
| 透明性 | 明确标识AI生成的内容 |

### 5.3 AI提示词设计

#### 5.3.1 续写提示词模板

```
基于以下上下文，续写故事：

【前文】
{previous_content}

【当前角色】
{character_info}

【世界观设定】
{world_setting}

【写作风格】
{user_style}

请续写约300字，保持风格一致，推动情节发展。
```

#### 5.3.2 润色提示词模板

```
对以下文本进行润色，保持原意但提升文采：

【原文】
{original_text}

【风格要求】
{style_requirement}

【注意事项】
- 保持原意不变
- 保持角色性格一致
- 提升语句流畅度
- 增强画面感
```

## 九、验收标准

### 9.1 基础功能

- [ ] 用户可以创建新小说并设置基本信息
- [ ] 用户可以添加、删除、排序章节
- [ ] 编辑器支持基本的文本编辑和格式化
- [ ] 内容自动保存，刷新后不丢失
- [ ] 字数统计准确实时

### 9.2 AI功能

- [ ] AI续写内容连贯、符合上下文
- [ ] AI润色保持原意，提升文采
- [ ] AI建议相关、有用
- [ ] AI响应速度合理（<5秒）

### 9.3 用户体验

- [ ] 界面简洁，操作直观
- [ ] 写作流程顺畅，不被技术细节打断
- [ ] AI辅助自然，不干扰创作
- [ ] 数据安全可靠，有备份机制

### 9.4 性能要求

- [ ] 编辑器响应流畅，无明显延迟
- [ ] 大文档（10万字+）编辑不卡顿
- [ ] AI请求不阻塞UI
- [ ] 内存占用合理

## 十、与现有功能的关系

### 10.1 共享组件

| 组件 | 来源 | 复用方式 |
|------|------|---------|
| AI服务 | AIService | 扩展，增加小说相关方法 |

### 10.2 独立模块

小说创作作为独立功能模块，与对话创作平行：

```
YourStory2
├── 模拟人生（Simulation）
├── 对话创作（DialogueAgent）
├── 小说创作（Novel）  ← 新增
├── 自传阅读（Autobiography）
└── 设置（Settings）
```
