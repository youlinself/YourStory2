## 1. 系统概述

模拟人生事件系统是游戏的核心玩法之一，玩家每年会触发不同类型的事件，通过选择不同选项来影响角色属性和人生轨迹。

## 2. 核心数据结构

### 2.1 GameEvent 接口

```typescript
interface GameEvent {
  id: string;                    // 事件唯一标识
  type: EventType;               // 事件类型
  era: number;                   // 所属时代索引 (0-9)
  title: string;                 // 事件标题
  baseText: string;              // 事件描述文本
  options: EventOption[];        // 选项列表
  minAge?: number;               // 最小触发年龄
  maxAge?: number;               // 最大触发年龄
  triggerCondition?: (           // 自定义触发条件
    state: GameState
  ) => boolean;
  skinRule?: (                   // 皮肤规则（动态文本生成）
    attrs: PlayerAttributes,
    history: ChoiceRecord[],
    tags: string[]
  ) string;
  tags?: string[];               // 事件标签
}
```

### 2.2 EventOption 接口

```typescript
interface EventOption {
  id: string;                    // 选项唯一标识
  text: string;                  // 选项显示文本
  successRate: {                 // 成功率计算参数
    energy?: number;             // 精力权重
    physique?: number;           // 体魄权重
    health?: number;             // 健康权重
    iq?: number;                 // 智商权重
    eq?: number;                 // 情商权重
    wealth?: number;             // 财富权重
    network?: number;            // 人脉权重
    fame?: number;               // 名望权重
  };
  successOutcome: EventOutcome;  // 成功结果
  failureOutcome: EventOutcome;  // 失败结果
}
```

```typescript
interface EventOutcome {
  description: string;           // 结果描述文本

  relicRewards?: string[];       // 奖励的遗物ID
  goldReward?: number;           // 金币奖励
  lifeCost?: number;             // 寿命消耗
}
```

## 3. 事件类型

```typescript
type EventType = 'fixed' | 'random' | 'npc_triggered' | 'world_event' | 'map_event';
```

| 类型 | 说明 | 触发方式 |
|------|------|----------|
| `fixed` | 固定事件 | 必定在指定年龄触发 |
| `random` | 随机事件 | 在年龄范围内随机触发 |
| `npc_triggered` | NPC触发事件 | 需要特定NPC存在 |
| `world_event` | 世界事件 | 全局性事件，可能影响多个玩家 |
| `map_event` | 地图事件 | 与地图探索相关 |

## 5. 事件触发与过滤机制

### 5.1 事件过滤流程

```
所有事件
    │
    ▼
┌─────────────────┐
│ 年龄范围过滤     │  minAge <= currentAge <= maxAge
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 触发条件过滤     │  triggerCondition(state) === true
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 锁定状态过滤     │  event.id ∉ worldState.lockedEvents
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 解锁状态过滤     │  unlockedEvents为空 或 event.id ∈ unlockedEvents
└────────┬────────┘
         │
         ▼
    可用事件列表
```

### 5.2 核心过滤代码

```typescript
// src/stores/simulationStore.ts
getAvailableEvents(): GameEvent[] {
  const { birthYear, currentAge, worldState } = this.getState();
  
  // 1. 获取基础事件
  let events = getEventsByBirthYear(birthYear);
  
  // 2. 添加条件事件
  events = events.concat(SCRIPT_CONDITIONAL_EVENTS);
  
  // 3. 修仙模式事件（110岁后）
  if (currentAge >= 110) {
    events = events.concat(SCRIPT_CULTIVATION_EVENTS);
  }
  
  // 4. 过滤
  return events.filter(event => {
    // 年龄过滤
    if (event.minAge !== undefined && currentAge < event.minAge) return false;
    if (event.maxAge !== undefined && currentAge > event.maxAge) return false;
    
    // 触发条件过滤
    if (event.triggerCondition && !event.triggerCondition(this.getState())) {
      return false;
    }
    
    // 锁定状态过滤
    if (worldState.lockedEvents.includes(event.id)) return false;
    
    // 解锁状态过滤
    if (worldState.unlockedEvents.length > 0 && 
        !worldState.unlockedEvents.includes(event.id)) {
      return false;
    }
    
    return true;
  });
}
```

## 6. 事件结果与属性变化

### 6.1 成功率计算

事件选项的成功率基于玩家属性加权计算：

```typescript
// src/stores/simulationStore.ts
getSuccessRate(option: EventOption): number {
  const { attributes } = this.getState();
  const weights = option.successRate;
  
  let totalWeight = 0;
  let weightedSum = 0;
  
  for (const [attr, weight] of Object.entries(weights)) {
    if (weight > 0) {
      weightedSum += attributes[attr as keyof PlayerAttributes] * weight;
      totalWeight += weight;
    }
  }
  
  // 基础成功率50%，属性加成最高50%
  const baseRate = 0.5;
  const attrBonus = totalWeight > 0 ? (weightedSum / totalWeight / 100) * 0.5 : 0;
  
  return Math.min(0.95, Math.max(0.05, baseRate + attrBonus));
}
```

### 6.2 结果处理

```typescript
// src/stores/simulationStore.ts
makeChoice(eventId: string, optionId: string): void {
  const event = this.getEventById(eventId);
  const option = event.options.find(o => o.id === optionId);
  
  // 1. 计算成功/失败
  const successRate = this.getSuccessRate(option);
  const isSuccess = Math.random() < successRate;
  
  // 2. 应用结果
  const outcome = isSuccess ? option.successOutcome : option.failureOutcome;
  this.applyOutcome(outcome);
  
  // 3. 记录选择历史
  this.recordChoice({
    eventId,
    optionId,
    success: isSuccess,
    description: outcome.description,
    age: this.getState().currentAge,
  });
}
```

## 7. 事件链机制

事件可以通过 `unlockEvents` 和 `lockEvents` 实现事件链，让某些事件的前置条件依赖于其他事件的结果。

### 7.1 事件链示例

```typescript
// src/data/eraEvents.ts
const SCRIPT_CONDITIONAL_EVENTS: GameEvent[] = [
  // 第一环：天才童年
  {
    id: 'genius_childhood',
    type: 'fixed',
    era: 0,
    title: '天才童年',
    baseText: '你从小就展现出非凡的智慧...',
    minAge: 6,
    maxAge: 8,
    options: [
      {
        id: 'genius_accept',
        text: '接受特殊教育',
        successRate: { iq: 0.8 },
        successOutcome: {
          description: '你进入了天才班...',
          attributeChanges: { iq: 5, eq: -2 },
          unlockEvents: ['young_scholar'],  // 解锁下一环事件
        },
        failureOutcome: {
          description: '压力太大，你感到疲惫...',
          attributeChanges: { health: -3 },
        },
      },
    ],
  },
  
  // 第二环：少年学者（需要前置事件解锁）
  {
    id: 'young_scholar',
    type: 'fixed',
    era: 1,
    title: '少年学者',
    baseText: '你的才华被一位著名教授看中...',
    minAge: 12,
    maxAge: 14,
    triggerCondition: (state) => 
      state.worldState.unlockedEvents.includes('young_scholar'),
    options: [
      {
        id: 'scholar_accept',
        text: '跟随教授学习',
        successRate: { iq: 0.6, eq: 0.4 },
        successOutcome: {
          description: '你在学术上取得了突破...',
          attributeChanges: { iq: 8, fame: 3 },
          unlockEvents: ['early_college'],  // 解锁第三环
          lockEvents: ['normal_youth'],     // 锁定冲突事件
        },
        failureOutcome: {
          description: '你无法适应高强度的学习...',
          attributeChanges: { health: -5 },
        },
      },
    ],
  },
  
  // 第三环：提前上大学
  {
    id: 'early_college',
    type: 'fixed',
    era: 2,
    title: '提前上大学',
    baseText: '你被破格录取到名牌大学...',
    minAge: 16,
    maxAge: 17,
    triggerCondition: (state) => 
      state.worldState.unlockedEvents.includes('early_college'),
    options: [/* ... */],
  },
];
```

### 7.2 事件链设计原则

1. **解锁条件明确**：每个事件链节点都应有清晰的解锁条件
2. **互斥事件处理**：使用 `lockEvents` 处理互斥事件
3. **分支收敛**：多条分支最终可以汇聚到相同结果
4. **避免死锁**：确保事件链不会导致游戏无法继续

## 11. 年度选项权重系统

每年玩家会看到3个加权随机选项：

```typescript
// src/stores/simulationStore.ts
const YEAR_OPTION_WEIGHTS = {
  combat: 41,    // 战斗
  elite: 20,     // 精英战斗
  event: 15,     // 事件
  wonder: 8,     // 奇观
  rest: 7,       // 休息
  shop: 9,       // 商店
};

function getYearOptions(): YearOptionType[] {
  const options: YearOptionType[] = [];
  const weights = { ...YEAR_OPTION_WEIGHTS };
  
  while (options.length < 3) {
    const totalWeight = Object.values(weights).reduce((a, b) => a + b, 0);
    let random = Math.random() * totalWeight;
    
    for (const [type, weight] of Object.entries(weights)) {
      random -= weight;
      if (random <= 0) {
        options.push(type as YearOptionType);
        weights[type as keyof typeof weights] = Math.max(0, weight - 10);
        break;
      }
    }
  }
  
  return options;
}
```

### 选项类型说明

| 类型 | 权重 | 说明 |
|------|------|------|
| `combat` | 41 | 普通战斗，可能获得经验和战利品 |
| `elite` | 20 | 精英战斗，难度更高但奖励更好 |
