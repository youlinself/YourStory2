## 🔧 技术注意事项

### 类型定义更新
以下类型需要更新以支持新功能:

```typescript
// src/types/novel.ts 需要添加的字段

export interface NovelChapter {
  // ... 现有字段
  tags?: string[];           // 章节标签
  annotations?: Annotation[]; // 注释
  notes?: string;            // 章节笔记
}

export interface Annotation {
  id: string;
  startPos: number;
  endPos: number;
  text: string;
  note: string;
  type: 'comment' | 'todo' | 'idea';
  createdAt: string;
}

export interface WritingGoal {
  id: string;
  novelId: string;
  type: 'daily' | 'chapter' | 'total';
  target: number;
  deadline?: string;
  completed: boolean;
}
```

### 存储服务扩展
`FileStorageService` 已添加以下方法:
- `ensureDirectory()`
- `saveJson()` / `loadJson()`
- `deleteFile()`
- `listFiles()` / `listDirectories()`
- `directoryExists()`
- `getDirectorySize()`
- `writeTextFile()`
- `deleteDirectory()`
