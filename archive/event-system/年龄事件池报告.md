## 三、事件触发机制

### 3.1 事件类型（`type` 字段）

| 类型 | 触发方式 | 说明 |
|-----|---------|------|
| `fixed` | 年龄匹配时必定出现 | 最稳定的事件来源 |
| `world_event` | 年龄匹配时必定出现 | 通常与年代背景相关 |
| `random` | 年龄匹配 + `triggerCondition` 满足时出现 | 需要满足特定条件 |

### 3.2 触发条件（`triggerCondition`）

```typescript
triggerCondition: (state: GameState) => boolean
```

常见条件类型：

| 条件类型 | 示例 | 说明 |
|---------|------|------|
| 属性阈值 | `state.attributes.iq >= 60` | 智力≥60 |
| 属性组合 | `state.attributes.physique >= 50 && state.attributes.energy >= 50` | 体力≥50 且 精力≥50 |
| 事件解锁 | `state.worldState.unlockedEvents.includes('young_scholar')` | 已解锁特定事件 |
| 年龄范围 | `state.age >= 35` | 年龄≥35岁 |
| 标签检查 | `state.hiddenTags.includes('genius')` | 拥有特定隐藏标签 |

### 3.3 事件过滤逻辑

```typescript
// src/stores/simulationStore.ts - getAvailableEvents()
const filterEvents = (events: GameEvent[]): GameEvent[] => {
  return events.filter((event) => {
    // 1. 年龄范围过滤
    if (event.ageRange) {
      const [minAge, maxAge] = event.ageRange;
      if (s.age < minAge || s.age > maxAge) return false;
    }
    // 2. 触发条件过滤
    if (event.triggerCondition && !event.triggerCondition(s)) return false;
    // 3. 锁定事件过滤
    if (event.id && lockedSet.has(event.id)) return false;
    return true;
  });
};
```

### 5.2 成功几率计算

```typescript
// src/stores/simulationStore.ts
const calculateSuccessRate = (option: EventOption, s: GameState) => {
  const w = option.successRate;
  let tw = 0, ws = 0;
  for (const [k, v] of Object.entries(w)) {
    ws += s.attributes[k as keyof PlayerAttributes] * (v || 0);
    tw += v || 0;
  }
  const base = tw > 0 ? ws / tw / 100 : 0.5;
  let bonus = 0;
  if (option.tagModifier && s.hiddenTags.includes(option.tagModifier.tag)) {
    bonus = option.tagModifier.rateBonus;
  }
  return clamp(base + bonus, 0.05, 0.95);
};
```

**成功几率影响因素**：
- 选项的 `successRate` 权重（如 `{ iq: 0.5, energy: 0.3 }`）
- 玩家对应属性值
- 隐藏标签加成（`tagModifier`）

## 七、已知问题与改进建议

### 7.1 已修复问题

| 问题 | 修复方案 |
|-----|---------|
| 10+岁事件池为空导致跳过 | 新增 `SCRIPT_GENERIC_EVENTS` 作为后备 |
| 部分年龄段事件稀疏 | 新增 `SCRIPT_SUPPLEMENTARY_EVENTS` 补充 |
| 属性 `wisdom` 不存在 | 替换为 `iq` 属性 |

### 7.2 改进建议

1. **增加10+岁年代专属事件**：当前10+岁主要依赖通用事件，建议为每个年代增加特色事件
2. **丰富事件链**：增加更多解锁/锁定机制形成的事件链
3. **动态事件生成**：基于玩家已解锁的事件和标签，动态生成个性化事件
4. **平衡属性影响**：确保各年龄段的事件能覆盖所有属性，避免某些属性难以提升

// src/types/simulation.ts
export interface GameEvent {
  id: string;
  type: 'fixed' | 'random' | 'world_event';
  era: number;                    // 时代编号（0-7+）
  ageRange: [number, number] | null; // 年龄范围，null表示全年龄段
  title: string;
  baseText: string;
  skinRule?: (attrs: PlayerAttributes, history?: EventRecord[], tags?: string[]) => string;
  triggerCondition?: (state: GameState) => boolean;
  options: EventOption[];
  isMilestone?: boolean;
}

export interface EventOption {
  id: string;
  text: string;
  successRate: Record<keyof PlayerAttributes, number>;
  successOutcome: EventOutcome;
  failureOutcome: EventOutcome;
  tagModifier?: {
    tag: string;
    rateBonus: number;
  };
}

export interface EventOutcome {
  description: string;
  attributeChanges: Partial<PlayerAttributes>;
  unlockEvents?: string[];
  lockEvents?: string[];
  relicRewardPool?: Relic[];
  triggerCombat?: boolean;
}
